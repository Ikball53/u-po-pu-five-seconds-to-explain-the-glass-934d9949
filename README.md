# Five Seconds to Explain the Glass

Entry for make.fun competition `u-po-pu-five-seconds-to-explain-the-glass-934d9949`.

One sentence a house cat says in its own defence five seconds after sweeping
a glass off the table: the glass was sitting in the cat's sunbeam, so it was
relocated to the floor. No apology, no confession, no remorse.

`main.py` writes the single sentence (61 characters) to `/output/entry.txt`,
deterministically, with no network access.

Run it with:

```sh
python3 main.py
```
